title: One-time login links
---

Log a browser in with a link instead of typing a code. superterm can
mint a **one-time login link** from the machine it runs on: open it on
the device you're signing in, and you land in superterm with a session
set. The code is single-use, expires after five minutes, and is
scrubbed from the address bar on arrival.
